# 🧙‍♂️ Hogwarts Audio English | 霍格沃茨音频精听魔法学院

基于 **Harry Potter（哈利·波特）青少年版原版音频与 VTT 字幕** 打造的沉浸式英语精听学习网站。

---

## ✨ 核心特色功能

1. **🎵 逐句同步精听播放器**
   - **时间戳高亮同步**：播放时实时高亮当前朗读句子，自动平滑滚动。
   - **点击任意句跳转**：点击字幕任意处直接定位音频播放。
   - **单句精听循环（Repeat 1）**：开启后当前句子播放完自动从头重放，适合反复听读揣摩。
   - **A-B 复读 / 重播本句**：支持一键重听当前句子或通过键盘快捷键秒级切换。
   - **多档语速调节**：0.75x ~ 1.5x 多档语速自由切换。

2. **⚡ 划词/点击查词 & 哈利波特魔法词典**
   - **点击任意英文单词**：即时弹出英音音标、词性、中文释义与英文解释。
   - **哈利波特独家魔法专有词库**：收录 *Muggle、Quidditch、Golden Snitch、Gryffindor、Galleon、Parseltongue、Butterbeer* 等原著特有词汇，附带原著背景背景与典故解析！
   - **一键收藏到魔法生词本**：自动关联当前朗读的原著上下文与出处章节。

3. **📜 魔法生词本 & 翻转卡片自测（Flashcards）**
   - 本地持久化存储，无需注册登录。
   - **背词卡片模式**：翻转卡片正面为单词与音标，背面为中文释义、原著典故与例句。
   - **支持导出 Anki / CSV**：一键导出词表至主流记忆软件。

4. **🎧 盲听磨耳朵 & ✍️ 挖词填空听写**
   - **盲听模式**：自动对英文字幕应用魔法模糊遮罩（Blur），悬停或点击单句才揭示，锻炼纯粹听力反应。
   - **听写模式**：自动挖空句中核心词汇，边听边在输入框中打字，即时判定正误！

5. **🎙️ 跟读录音与原音对比（Shadowing）**
   - 浏览器内置录音功能，录制自己的发音。
   - 支持原作者原版朗读与用户录音同台比对回放，纠正连读、重音和语调。

6. **🏰 霍格沃茨双重主题**
   - 霍格沃茨夜间星空黑金主题（默认）。
   - 复古魔法羊皮纸主题（Parchment）。

## ☁️ Cloudflare R2 音频与字幕配置指南

本系统提供三种灵活的数据对接模式：

### 模式 A：本地/演示模式（即开即用）
- 内置第 1 章《The Boy Who Lived》完整的双语精听字幕与示范音频，即使尚未配置 R2 也能立刻上手体验所有功能。

### 模式 B：通过后端 S3 密钥代理读取 R2 私有桶（推荐）
1. 在项目根目录复制环境变量模板：
   ```bash
   cp .env.example .env
   ```
2. 在 `.env` 中填写你的 Cloudflare R2 信息：
   ```env
   R2_ACCOUNT_ID=你的Cloudflare账户ID
   R2_ACCESS_KEY_ID=你的R2_Access_Key_ID
   R2_SECRET_ACCESS_KEY=你的R2_Secret_Access_Key
   R2_BUCKET_NAME=harrypotter-audio
   PORT=3001
   ```
3. 启动后端代理服务：
   ```bash
   npm run server
   ```
   后端支持 HTTP Range 请求头（实现秒级拖动音频进度条）和跨域代理。

### 模式 C：R2 公网域名直接读取
- 如果你在 Cloudflare R2 控制台为存储桶绑定了自定义域名（如 `https://media.yourdomain.com`）或开启了 `r2.dev` 访问：
- 在网站右上角打开 **「R2 设置」**，选择 **「公网 CDN / 域名」**，输入 Base URL 即可。
- 文件命名规则：
  - 音频：`{BaseURL}/book1/ch01.mp3`
  - 字幕：`{BaseURL}/book1/ch01.vtt`

## 🚀 本地快速启动

```bash
# 1. 安装依赖
npm install

# 2. 启动前端 Vite 开发服务器（端口 3000）
npm run dev

# 3. （可选）启动 R2 本地代理服务（端口 3001）
npm run server
```

在浏览器打开：`http://localhost:3000` 即可开始魔法英语学习之旅！

## ⌨️ 快捷键一览

| 快捷键 | 功能 |
| :--- | :--- |
| **Space（空格）** | 播放 / 暂停音频 |
| **← / →** | 上一句 / 下一句精听句子 |
| **R** | 重播当前句 |
| **L** | 开启 / 关闭单句循环 |
| **M** | 切换 精听 / 盲听 / 听写模式 |
| **↑ / ↓** | 音量调大 / 调小 |
